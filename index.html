NBMEcalc Score Tools for NetBeans

A small local workflow for creating, validating, and copying structured practice-exam score worksheets while working in Apache NetBeans.

The extension is an educational worksheet helper. It does not provide medical advice, official score reports, or a replacement for an examination authority.

Why keep the worksheet in the IDE?

Study notes and small analysis projects often need the same fields repeated: the assessment source, correct and total items, an estimate, and its confidence bounds. The plugin keeps that structured record on the local clipboard, validates the basic constraints, and produces a concise summary that can be pasted into notes or an issue discussion.

When an interactive estimate is the better next step, use the USMLE Step score calculator. The browser workflow and this NetBeans helper have intentionally different responsibilities: the site is interactive, while the plugin never sends worksheet data over the network.

Install the verified NBM bundle

  1. Install JDK 17 or newer and Apache NetBeans 22 or newer.
  2. Download nbmecalc-netbeans-0.1.0.nbm from Maven Central.
  3. In NetBeans, open Tools → Plugins → Downloaded, choose Add Plugins, select the downloaded .nbm file, and restart when prompted.

The published coordinate is io.github.jiankn:nbmecalc-netbeans:0.1.0. The source, Javadoc, and signatures are published alongside the bundle for reproducible review.

Create and validate a worksheet

Open Tools → NBMEcalc → Copy score worksheet, then adjust the copied JSON to match the practice assessment you are reviewing. Select Validate worksheet from clipboard to check required fields, valid item ranges, and the ordering of the confidence interval.

{
  "source": "NBME 10",
  "correct": 160,
  "total": 200,
  "estimatedScore": 245,
  "confidenceLow": 238,
  "confidenceHigh": 252
}

A valid record requires all six fields. correct must be between zero and total; confidenceLow must not exceed estimatedScore; and estimatedScore must not exceed confidenceHigh.

Use the result without exporting personal data

Copy validated summary creates a short text result for a local study note. Open calculator is an explicit browser action, so nothing is opened or transmitted merely by creating or validating a worksheet.
